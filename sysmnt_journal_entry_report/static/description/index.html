Journal Entry PDF Report (Arabic & English)

This module enables you to print journal entries in a bilingual PDF format (Arabic & English), making it suitable for financial operations in multilingual environments, especially across the MENA region.

Key Features:

  • Adds a "Print Journal Entry" button to the journal entry form.
  • Generates clean and structured PDF reports with bilingual content.
  • Arabic and English formatting for labels and values.
  • Compatible with Odoo 18.
  • Designed for accounting departments needing professional, compliant documentation.

Use Cases:

  • Audit preparation.
  • Accounting documentation for local authorities.
  • Internal financial reviews.
  • Arabic-speaking financial users in GCC countries.
