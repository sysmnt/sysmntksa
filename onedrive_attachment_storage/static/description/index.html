How It Works

Simple setup, powerful automation. Get started in less than 10 minutes.

1

Register Azure AD Application

Create an app registration in Azure AD, grant API permissions (Sites.ReadWrite.All, Files.ReadWrite.All), and get your credentials. Full documentation included.

2

Configure in Odoo

Navigate to Settings → Technical → OneDrive Storage. Enter your Azure credentials, click "Test Connection" to verify, then enable automatic uploads.

3

Migrate Existing Files

Click "Sync Existing Attachments" to start migrating your current files. Progress is tracked automatically. Continue working while migration runs in background.

✓

Done! All Future Uploads Go to OneDrive

Every attachment uploaded anywhere in Odoo is now automatically stored in OneDrive. Users download files seamlessly with no workflow changes.
